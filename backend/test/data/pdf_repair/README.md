# PDF 修复的人工微型 oracle

本目录不存完整论文、用户 PDF、下载的 MD 或由待测算法自动生成的 expected。人工短例位于 `test/unit/knowledge/test_pdf_repair.py`，覆盖两份不同论文差异报告确认的文字、数值、单位、引文、字形与新增重复类别；相应负例明确区分可证明修复与保持未决。两篇论文的错误数不能用作 A/B。

验收时固定同篇同一次 OXR 输出，不重新请求 OCR 来制造不同基线。知识库附属 JSON 的 `metadata.pdf_repair` 保存原始块/Markdown、原生证据、源文件及输入摘要、规则版本、R1/R2 补丁和最终正文摘要。`publication_asset_map` 用于回放时把原始占位符替换成同次解析的鉴权资源。

规则重放应从 `ocr_blocks` 深拷贝开始，按顺序应用接受的 R1/R2 补丁，以 blocks 重新渲染后替换发布资源；未经证据验证的模型回复不进入补丁历史。原始 OCR 的科学错误标为未决不能计作修复成功。性能比较需分别记录 OCR、规则、文字/视觉请求、共享排队、缓存命中及独立图片任务耗时。

本机按用户要求只做静态语法和差异检查，全部应用测试与论文效果验收由另一台机器执行。
