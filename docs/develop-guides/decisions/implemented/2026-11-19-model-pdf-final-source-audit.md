# 模型 PDF 在发布前核对最终正文

状态：implemented
类型：feature
Owner：backend/package/yuxi/knowledge/parser/pdf_final_source.py

发布前的宽泛程序核对已由[成稿终审](2026-11-20-model-pdf-final-review.md)取代。本记录保留跨页接续的定位与人工处理决定。

## 问题

现有原文疑点扫描在模型复核前执行，只登记特定引文和局部符号。漏字、引文中误加逗号、数字被写成字母、定位上下文跨行时，最终稿可能保留错误，同时没有人工待确认项。

## 决策

### 实现方案

模型 PDF 识别服务在整页复核、跨页接续和 Markdown 渲染之后，逐页核对用于渲染的最终块。以原生行和段落位置匹配同栏内容，双向登记文字增删改、未对齐的原文和原生行序冲突。页眉页脚依据页边位置及同位置文字判定。保留数字、标点以及有意义的词内空白差异。只有可定位的文字片段提供替换候选。公式符号、表格行列、上下标、未对齐区域、未覆盖的栅格原图及无可靠文字层的页保留原图待核。

最终核对服务将新增疑点并入现有校对记录后派生复核状态、补齐裁图，随 Markdown 一起发布。检查到跨页接续冲突时，可在同一校对界面取消接续。英文相邻片段缺少分隔时，可由人工确认用空格连接。修改使用现有文件版本、校对版本和当前接续检查。核对本身不发模型请求，也不改正文。校对未解决时沿用自动入库的暂停路径。

## 替代方案

- 只扩充复核前扫描规则。开销较小，无法检查模型修改后留下或引入的差异。
- 使用整篇原生文字覆盖最终模型结果。错误文字层、表格读序及公式上下标可能覆盖正确的识别结果。

## 后果

自动校对后仍存在的差异可以交人工确认。复杂版面和不可靠文字层扩大人工核对范围。每页待办超过细项上限时，保留可定位的候选，并用整页记录覆盖其他待核区域。少量栅格装饰按面积过滤。真实运行准确率、人工工作量和多文档覆盖由部署后的样本回读确定。
