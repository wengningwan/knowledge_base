# 论文证据分块、来源审查与同题对照

状态：implemented
类型：feature
Owner：backend/package/yuxi/knowledge/chunking/paper.py

## 问题

严格分隔策略按换行切开 Markdown 公式和说明，图片与图注、表格和标题失去关联。固定四行的分块预览无法完整审查。解析版面信息与检索块之间缺少可回查的来源；以块序号作为不同切分方案的共同金标准会使比较失真。

## 决策

### 实现方案

`paper` 是显式选择的论文证据策略，沿现有解析后入库、PostgreSQL chunk 事实和 Milvus 派生索引运行。章节、完整公式及定义、图片与图注、Markdown/HTML 表格与标题组织在实际检索正文中。显示编号的公式解释仅在编号吻合时附加；图表说明两侧都有候选时保留独立内容并提示歧义。参考文献保留在原文，不成为检索块或实验条件来源。

分块中的实验跨段关联由[Paper 职责边界](2026-11-04-paper-chunking-boundary.md)收敛为仅组织原文，不再追加实验条件。长度是组合目标，单个完整公式/表格可超过目标并提示；超出 Milvus 字段容量时在清理旧索引前显式拒绝。

`KnowledgeChunk.source_metadata` 是独立的可空 JSON，由分块模块产生、repository 持久化，Milvus executor 向预览和查询回填。它保存 Markdown 指纹、分块策略、章节、内容类型、证据标识及显式多来源范围。行号是一基闭区间；字符范围按 Unicode 码点零基左闭右开。不连续来源保留多个范围。PDF 页码仅来自同次解析、唯一逐字匹配的真实版面块；其余只提供 Markdown 位置。知识 schema 3→4 由 storage-migrator 幂等升级，1/2 版本继续走相邻升级链，旧记录保持空来源。

检索回填核对 PG 中知识库、文件、chunk、顺序与正文，过滤孤儿及陈旧向量命中。内容响应返回当前 Markdown 指纹。前端保留全部事实块，不经正文合并省略重复块；卡片可用键盘展开完整证据正文、保留换行，并逐个打开独立来源窗口。Paper 预览按策略或既有证据结构识别，章节元数据与生成前缀一致时隐藏开头的论文名和章节行，章节通过卡片标签展示；正文内的同名文字、通用块及原始检索内容均保留。新来源需指纹及坐标一致，旧字符范围需与当前原文逐字吻合，缺失或失效时不伪造定位。

同题对照命令只读用户准备的零重叠 Separator 和 Paper 知识库，使用固定源指纹、原文字符范围、必要条件及答案要点，固定检索参数与模型。独立 Milvus executor 只连接明确指定的已有数据库、加载现有兼容索引，禁止创建、重建或默认库回退。报告区分前 K 块召回与实际前五块回答上下文，保存真实 prompt、答案和待人工核验字段。条件词面覆盖不代表样品归属或科学正确性；未运行模型时不产生答案质量结论。配置与操作由[同题对照参考](../../../advanced/chunking-comparison.md)拥有。

## 替代方案

- 仅调分隔符可减少裸公式标记，不能闭合章节上下文、图表关联和来源审查。
- 整体导入试验工作台会重复文件状态、审核和服务 Owner；仓库只借鉴结构规则，不依赖外部路径或试验产物。
- 将来源放入图谱 `extraction_result` 会混淆文档来源与图谱抽取，两者分别保存。
- 独立证据服务、替换向量引擎或扩建评估数据库会增加当前用例不需要的部署和维护边界。

## 后果

通用策略和全库默认值保持原行为，已有文件需显式重新入库才能获得新分块及来源。General 等改写正文的策略、重叠 Separator 尚不能保证完整精确来源，不纳入该对照。规则的名称与结构识别范围有限，原文和人工核验继续承担科学语义判断。

Paper 的同行数字小节、相邻英文续句及来源 PDF 页定位由[小节与来源页决定](2026-11-02-paper-subsections-and-source-pages.md)补充；只使用当前一套实现与固定策略标记，见[当前实现决定](2026-11-05-paper-single-implementation.md)。已有分块和检索正文继续保留。

Paper 的浮图续接、同行父子标题及图表独立上下文由[正文连续性与处理边界决定](2026-11-04-paper-evidence-continuity.md)补充，当前规则以分块 Owner 为准。

## 验证

纯规则及对照 unit 使用独立合成论文和冻结原文范围；负向覆盖公式编号冲突、图注两侧歧义、普通谓语冒充实验名、不同样品/章节、重复文本、Unicode 坐标、小数和负数条件误匹配。真实论文的离线结构检查仅证明无裸公式标记、说明同块及范围合法，不作为检索准确率。

Web unit 与真实 Vue 组件的模拟 API 浏览器检查覆盖完整展开、重复块、非连续来源、版本失效、旧块 Unicode、文件切换及迟到响应、明暗主题和窄屏。模拟 API 不证明后端集成。PostgreSQL 升级/持久化 integration 和 API→Durable Task/worker→PG/Milvus 入库 E2E 已有可执行测试，当前机器没有真实底座，状态为 Not run，由部署环境验证。真实 Embedding、检索及回答质量也为 Not run，不宣称准确率提升。
