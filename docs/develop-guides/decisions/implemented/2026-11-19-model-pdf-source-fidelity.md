# 模型 PDF 参照原生文字核对转写

状态：implemented
类型：bug-fix
Owner：backend/package/yuxi/knowledge/parser/pdf_recognition_source.py

## 问题

逐页视觉模型及可选复核会漏写引文数字，误读姓名，修改已印出的拼写或科学符号。回执格式正确时仍可能留下这些偏差。PDF 行末断词与原生公式读序会产生另外的表面差异。

## 决策

### 实现方案

模型识别及可选复核结束后，按页读取 PDFium 原生字符和位置，对同页同区域的段落和独立公式做局部核对。方括号引文在相邻文字唯一且数字有位置证据时列出候选，唯一匹配的单字和点号差异同样列出候选。独立公式能定位斜线附近的电荷差异时登记原图待核。未决项复用现有自动入库暂停规则，下载正文保留识别结果，人工保存修订后才更新。段落已有修订时，基于旧正文的整段候选仍显示为对照，编辑器从当前正文继续。解析元数据记录原生文字页数、适用块数、有对照位置的块数、疑点数及读取失败的页码。

## 替代方案

- 用整段原生文字覆盖识别结果。原生文本会受编码、上下标与双栏顺序影响，整段覆盖也会带回 PDF 行末断词。
- 按原生数字自动替换同位置的模型引文。扫描 PDF 的不可见文字层也能提供数字、字号和位置，自动采纳可能覆盖正确的视觉识别。
- 让模型再次复核整页。已有可选复核可以补充视觉证据，此项检查需要从原文件独立取得可定位的文字证据。

## 后果

原生字形映射有误、缺少定位、存在重复上下文或数学符号被分离时，核对覆盖有限。公式的读序和上下标仍需结合原图确认。行末断词与排版空白留给模型识别和 Markdown 段落排版处理。新结果在重新解析后生成。
