# PDF 复核与插图说明的有限重试

状态：implemented
类型：bug-fix
Owner：backend/package/yuxi/services/pdf_model_execution.py

## 问题

模型逐页识别可在失败后重试。单页复核和跨页复核直接读取模型 JSON 字段，响应缺字段或连接中断时整项进入未完成。插图说明的 429 直接结束单图请求。

## 决策

### 实现方案

复核服务校验完整 JSON 回执、修改类型和块引用，单页修改先应用到独立副本。协议错误、连接失败、供应商超时或暂时不可用时，同一单页或跨页检查最多重试一次。

插图说明遇到 429 后最多重试当前图片一次。供应商给出有效 `Retry-After` 时按该时间加随机间隔等待，供应商要求超过 60 秒时结束当前图片。没有有效提示时等待 60–65 秒。任务剩余时间不足以等待时结束当前项。每次调用重新经过共享并发准入和用量记录，等待在共享请求槽外进行，期间遵循任务取消与截止时间。

## 替代方案

- 开启 SDK 自动重试。多次真实请求会共用一次文档执行器记录，且无法处理正文复核的协议错误。
- 重跑整份文件。会重新处理已经识别和复核成功的页面。

## 后果

最终失败保留已识别正文或原图，并单独标记复核或图片说明未完成。重试最多增加一次单项模型用量和等待。成功通过协议校验仍需逐页对照 PDF 确认文字内容。
