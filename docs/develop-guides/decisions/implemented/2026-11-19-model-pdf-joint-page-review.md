# 同一页的整页复核随附原文疑点

状态：implemented
类型：feature
Owner：backend/package/yuxi/services/pdf_recognition_review_service.py

## 问题

整页复核先查看识别稿，随后独立请求复核 PDF 文字层发现的疑点。整页复核缺少对应引文、字形和公式的候选证据，有疑点的页面还要额外请求。

## 决策

### 实现方案

页识别完成后，识别服务对初稿执行同页原生文字核对。复核服务在同一个 `review-page-N` 请求中发送初稿、疑点、整页图和两栏放大图。回执的 `changes` 和 `decisions` 分别给出整页修改和逐处结论，两部分通过校验后一次应用。文字疑点采用程序已登记的候选。模型重复回传的文字仅在与候选完全一致时接受。公式只写入通过原有范围校验的局部变化。

整段替换只有在疑点及近邻文字在原段落和新段落中均唯一且原样保留时才生效，局部偏移随之更新。覆盖疑点的整段替换或删除进入人工校对。请求最终失败时保留初稿及疑点，记录页面复核未完成。原生文字缺失的页面仍可整页复核，未启用正文校对模型的疑点直接进入人工。跨页续接使用已经校对的页面。

[先整页校对后另发局部请求的决定](../archived/2026-11-19-model-pdf-source-visual-review.md)由本决定取代。

## 替代方案

- 保留整页后再单独校对的方式。两次模型调用可以独立成功，疑点要在整页校对完成后才能得到模型判断。
- 将疑点当作整页自由改写提示。响应更短，服务端无法验证模型对每处疑点的决定及改动范围。

## 后果

有疑点的页面共用一次常规整页复核，模型初次校对时已经能看到定位证据。提示词更长，回执格式错误时重试同一个页面请求。局部疑点基于初稿，整页复核新补内容继续依靠整页校对。实际耗时及识别准确率通过部署后的对照复跑观察。
