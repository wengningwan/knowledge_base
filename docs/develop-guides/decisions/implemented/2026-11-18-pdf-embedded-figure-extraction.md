# 模型识别优先使用 PDF 内嵌图像

状态：implemented
类型：bug-fix
Owner：backend/package/yuxi/knowledge/parser/pdf_native.py

## 问题

模型识别的图框有时漏掉曲线、数据点或坐标轴。按模型图框渲染页面区域也可能把相邻正文和图注截进导出的图片。

## 决策

### 实现方案

模型识别提供图块身份和同页位置。PDF 解析器按图框重叠匹配图像对象，对上下偏移的图框允许使用双方唯一的同栏紧邻图像。归属明确的多张子图按 PDF 中的位置合成一张 PNG。纯矢量图、匹配有歧义或无法提取的图沿用原页区域渲染，并记录诊断。文档组合统一把同一张图交给 Markdown 和插图解释。

## 替代方案

- 扩大模型截图框。可保留图外标注，但框的位置仍依赖模型，并可能混入相邻内容。
- 直接导出页面全部图像对象。可以完整提取每个对象，容易将页背景、重复图像和装饰物当作论文插图。

## 后果

模型图框用于找图，匹配成功后图像对象的范围决定输出。独立绘制在内嵌图像之外的标注需要依靠正文图注或原页查看。纯矢量图仍取原页区域。已有导出文件需要重新解析并下载才能使用新产物。
