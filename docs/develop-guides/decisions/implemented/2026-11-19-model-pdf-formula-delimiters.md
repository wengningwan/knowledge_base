# 模型 PDF 的独立公式统一定界

状态：implemented
类型：bug-fix
Owner：backend/package/yuxi/knowledge/parser/pdf_recognition.py

## 问题

模型可能在独立公式块内部用行内数学定界符包住一部分内容。例如反应式的箭头由一对美元符号包围，写 Markdown 时再给整式加显示定界符，生成无法可靠渲染的嵌套公式。

## 决策

### 实现方案

模型回执契约要求返回裸 LaTeX。识别、自动复核和人工公式替换统一在写入独立公式块前处理。公式数学范围内成对的美元及 LaTeX 显示或行内定界符剥除，保留转义、字面文本和受支持的文本参数内的行内数学。已有独立显示的公式及其明确的外置编号各自保留，连写公式沿用明确的顶层末尾编号拆分。

歧义或不配对的定界符进入现有模型回执拒绝与重试，人工公式替换直接拒绝保存错误内容。公式体残留连续美元符号时同样拒绝，避免 Markdown 把它读成公式提前结束。旧文档的块与 Markdown 一致性检查继续使用现有渲染函数。

## 替代方案

- 仅增加提示词约束。模型偶尔偏离格式时仍会产出嵌套。
- 在统一 Markdown 渲染阶段替换所有美元符号。会影响行内公式和已有文档校对的一致性检查。

## 后果

新写的模型独立公式每式使用一对显示定界符。已生成的旧导出可在重新解析后获得规范定界，或通过当前人工公式替换保存受影响块。其他 LaTeX 语法、数字与化学符号仍由原文和阅读器核对。
