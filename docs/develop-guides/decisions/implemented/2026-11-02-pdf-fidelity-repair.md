# PDF校对的完整目标与保真边界

状态：implemented
类型：bug-fix
Owner：backend/package/yuxi/knowledge/parser/pdf_review_contract.py

## 问题

字符差异可截断公式和词界；局部性检查无法拦截上下标降级、拼词或错误清理原文标点。模型的无需修改回执也不能消除独立证据冲突。逐字校对没有覆盖标题层级及图文续接。

## 决策

### 实现方案

parser在登记目标时扩展为完整内联单元，重建完整块后验证数学结构、词界和原文脚本；等价排印保留原串。有独立证据的真实纠错可应用，未决冲突保留正文并记待核。service使用有邻近上下文的实际裁图，明确标记局部冲突并保留模型建议、校验接受与实际应用结果。结构Owner使用编号、几何与原生行证据恢复结构，不向正文注入报告。完整队列、共享并发和用量统计继续生效。

## 替代方案

仅加强提示词不能拦截实际损坏。锁定所有科学token会阻止真实纠错。全部相信原生文字层无法处理字体映射错误。放宽失败补丁检查会扩大错误写入。

## 后果

有限语法无法证明任意复杂公式正确，缺少可靠原生几何时，脚本降级和原文标点改变保留原文及拒绝记录。逐个原有脚本按基字出现位置与作用范围核对，不能以其他位置新增脚本抵消丢失。模型和原生候选未解决的可靠冲突显示待核；完成请求不等于证明内容正确。规则处理可证明的局部词错误，减少整段视觉输出；性能结论仍需实际任务验证。
