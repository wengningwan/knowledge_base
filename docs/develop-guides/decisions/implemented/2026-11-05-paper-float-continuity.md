# Paper 浮动表格、数值续句与显式脚注

状态：implemented
类型：bug-fix
Owner：backend/package/yuxi/knowledge/chunking/paper.py

## 问题

同配置的 v4 实际导出中，正文图号、连续图注、子图、题名、日期和文末层级得到修正，来源坐标及正文可逐字重建；仍有明确半句被浮动表格隔开，以及数值列表在图片两侧断开。表头上标对应的紧邻脚注被单独索引，完整表格缺少原有说明。全角句点的 Fig．标记未识别为图注。

## 决策

### 实现方案

[Paper 分块器](../../../../backend/package/yuxi/knowledge/chunking/paper.py)将图、表及其说明视为可跨越的浮动单元；只有正文两侧仍满足同节、未完句、续句形式和明确对象身份约束时才续接。表格正文保持独立，不从表格抽取实验条件。公式、代码与章节变化继续阻止续接。

数值开头仅接受前文以一个数值和 and/or 结尾、后文紧接数值的显式并列形式；其他数字开头继续独立。紧邻表格后的单字母 LaTeX 上标脚注，仅在原表体包含同一上标、同节且原文间隔只有空白时附到表格，保留各段原文范围；正文重组后的相邻不能代替原文紧邻。全角句点只参与标记识别，不替换源文字。

[预览](../../../../web/src/utils/chunkPreview.js)按固定策略、既有证据结构及完整上下文前缀识别数据；来源指纹与坐标检查继续执行。后端只保留一套当前算法，策略标记见[当前实现决定](2026-11-05-paper-single-implementation.md)，样品边界见[续句的样品冲突范围](2026-11-05-paper-continuation-sample-boundary.md)。本决定补充[多样本结构边界](2026-11-04-paper-multisample-structure.md)，保留[Paper 分块职责](2026-11-04-paper-chunking-boundary.md)。

## 替代方案

强行按长度拼接整节会合并独立正文。允许任意数值续接会误合并新测量段或编号列表。按内容猜脚注或从方法段追加条件会越过结构边界。保留所有断点会使检索结果遗漏原句的后半部分。仅增加版本枚举使展示逻辑继续跟随规则批次改变。

## 后果

浮动表格不会证明文本连续性，续接仍依赖两侧文本和章节。缺字、重复正文、错误科学符号和混入广告属于解析内容问题，本决定不修复。图表保持独立块；表格的显式脚注按原文附入，无法匹配时继续独立。已有索引需重新入库，规则不追改旧数据。

## 验证

Inspected：回读用户部署端 v4 的5份同配置导出，257块与1079个来源范围的原文坐标和正文重建一致，59处图片引用完整；这些是输入材料的证据。确认表格两侧的4组半句、图片两侧的2组数值并列、一个显式表脚注及全角图注标记仍需结构处理；原 PDF 相关页核对了浮表位置与脚注归属。

Inspected：独立 Reviewer 复审 v5 代码未发现剩余必改项；`git diff --check` 已执行且通过。静态审查不替代重新入库后产物与页面回读。

Inspected（v5 实际导出）：三篇分别为53、52、26块，共131块、596个来源范围。原文未变，正文按原文范围逐字重建，36处图片引用全部保留。两组数值续句、三组跨表续句与表格上标脚注符合预期；剩余一组跨表半句受到整段样品判断阻止，见后续决定。没有煤文 v5 产物，Fig．6 与界面交互仍未验证。
