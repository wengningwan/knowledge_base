# Paper 续句的样品冲突范围

状态：implemented
类型：bug-fix
Owner：backend/package/yuxi/knowledge/chunking/paper.py

## 问题

部署端 v5 的三份实际导出已修复两组数值续句、三组跨表续句及一个表脚注，原文与来源完整；仍有一个半句停在 more acute，后段以 reaction occurred. 续接。后段后续独立句提及其他样品，整段样品集合被误用来否决开头续句。多段连字符样品名还会被截短，导致同系列不同配比的样品无法准确区分。

## 决策

### 实现方案

[Paper 分块器](../../../../backend/package/yuxi/knowledge/chunking/paper.py)能确认句界时，只用后段开头的续句判定字面样品冲突，保留前段样品和显式对象标识约束。句界扫描跳过行内数学、单字母缩写和常见论文缩写，避免将小数、Fig.、Eq. 或 Ref. 当句末；标点后只有普通首字母大写英文词或已到段末才作为候选句界，其余继续保守检查整段。正文仍按完整原文范围归组，不切割或改写后段，不补入条件。

字面样品识别保留完整连字符标记，以数字或末段 x 区分普通连字符词；MGA-700-2 与 MGA-700-4 不共用截短标识。章节、公式、代码、未完句和明确续句约束不变。算法仅维护当前一套，固定策略与预览识别由[当前实现决定](2026-11-05-paper-single-implementation.md)维护。

本决定补充[浮动表格、数值续句与显式脚注](2026-11-05-paper-float-continuity.md)，不改变[Paper 分块职责](2026-11-04-paper-chunking-boundary.md)。

后续[中文与双语图表结构](2026-11-05-paper-bilingual-structure.md)补充双语说明、中文续句与前置题名结构；当前算法由对应代码维护。

## 替代方案

删除样品保护会误合并不同对象。用整段样品集合阻止续接会使后续独立句影响当前半句。按正文含义猜测样品等价或补写实验条件超出结构职责。为某一篇原句硬编码放行失去通用性。

## 后果

能确认句界时，后段后续句不再充当开头续句的样品冲突证据；不能确认时保守检查整段，显式对象标识的整段约束始终保留。句界仅服务保守的结构判断，不构成完整语言理解。解析原文中的插文、重复和科学符号错误继续保留给解析校对。已有索引需要重新入库。
