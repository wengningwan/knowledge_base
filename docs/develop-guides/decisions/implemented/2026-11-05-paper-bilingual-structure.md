# Paper 中文与双语图表结构

状态：implemented
类型：bug-fix
Owner：backend/package/yuxi/knowledge/chunking/paper.py

## 问题

未参与制定 v6 规则的中文双语论文实际导出共65块。176个来源范围可逐字重建正文，11处图片引用完整，但结构验收未通过：中文图表引用句被误认图注，双语同编号说明拆开，带文字的全角子图标记落入正文，中文半句被浮图隔断，普通表注与表格分离。前置封面题名没有 Markdown 标记，正文重复中英文题名还被当作章节，使未编号前言继承题名。

## 决策

### 实现方案

[Paper 分块器](../../../../backend/package/yuxi/knowledge/chunking/paper.py)先解析原文单元，再组织明确的子图链与同编号双语说明，执行唯一图表配对，先确定表注再判断原文续句及公式归属。表注顺序与引用续句的补充边界见[显式表注决定](2026-11-05-paper-citations-and-table-notes.md)。续句不再先于图表结构识别，避免子图标签阻断正文或正文移动影响图注候选。

中文图号/表号后接明确谓词的原文继续作为正文。相邻、同节、同类型、同编号且一中一英的两个图注视为同一个说明单元；不同编号、同语种重复说明或中间存在正文时保持独立。裸标记与带说明文字的子图链统一要求同节、图与a/b/c标签按原文紧邻关系连续交替、标签从a依次递增，且后面有明确图注；单图独立标记等待唯一图注归属。扫描不提前归图，部分取代关系与集中验收见[结构边界决定](2026-11-05-paper-structural-boundaries.md)。

中文未完句两侧仍须同节且显式对象标识不冲突；句末中文标点、公式、代码与章节变化阻止续接。表格后原文紧邻的注:/Note:说明与表格同块，说明段保留独立范围，不从方法段补条件。中文显式公式引导与原公式/定义归组。

未标记的首个文字行只有与文件名题名逐字相同（忽略空白与大小写）时才作为论文题名。在编号章节或 Introduction、Methods、引言等明确正文栏目出现之前，完整题名的重复（含两行完整匹配）按元信息保留，并短暂开放另一语种题名匹配：候选只取首个无章节、长度至少20且汉字有无与已知题名不同的前置文字，必须与当前标题逐字相等。遇普通章节即关闭该匹配范围，另一语种重复题名消费后也关闭；不把任意前置文字升为题名，不推断翻译，不拼写或修改标题。前言没有明确章节时使用正文上下文。

收稿日期、作者简介、基金项目等明确的中文字段单独保留为元信息，英文摘要的明确半句可跨这些字段续接；普通正文中提到日期、作者或项目不触发该结构。

用户明确取消推荐宣传过滤，封面推荐文章、二维码及宣传文字全部继续保留；不新增删除、排除检索或基于关键词的过滤。后端只维护一套当前算法，不输出编号；固定策略与预览识别见[当前实现决定](2026-11-05-paper-single-implementation.md)。

本决定补充[续句的样品冲突范围](2026-11-05-paper-continuation-sample-boundary.md)和[多样本结构边界](2026-11-04-paper-multisample-structure.md)，继续遵循[Paper 分块职责](2026-11-04-paper-chunking-boundary.md)。

## 替代方案

按最近图表绑定双语说明会误关联不同编号。根据中文内容猜图意或翻译标题会制造事实。全篇拼成一块掩盖结构问题。删除推荐宣传违反用户最终选择；跨其他段落补实验条件越过分块职责。

## 后果

双语说明和子图按可检查的文字标记归组，不根据图意、距离或翻译推断归属。中文续接仍采用同节、未完句和对象约束；图表说明和标题的来源范围独立保留。推荐宣传不新增过滤，解析原文中的错字、科学符号和版面内容准确性仍由解析校对负责。多来源组装可能产生超目标块，继续保留全文并提示。
