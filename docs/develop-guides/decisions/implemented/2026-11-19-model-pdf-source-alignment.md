# 模型 PDF 局部原文核对覆盖跨行和定位偏移

状态：implemented
类型：bug-fix
Owner：backend/package/yuxi/knowledge/parser/pdf_recognition_source.py

## 问题

模型分块坐标存在偏移，印刷上标引用也会被原生文字拆行。启用原文核对的真实解析只发现部分差异，漏过段尾范围引文、跨行引文、坐标偏出区域的姓名或词语，同一印刷行的额外连字符，以及数学等价但排印不同的公式分组。

## 决策

### 实现方案

复用[逐页原文核对](2026-11-19-model-pdf-source-fidelity.md)和未决校对列表。同一印刷行的连续原生字形在上下标导致片段分离时重新对齐。程序用同栏的近邻原生行补足引文左侧证据，并比较单号和段尾的编号范围。段尾只剩短后文时也在整页确认唯一性。小幅纵向定位偏移由同栏位置和唯一上下文共同约束。可证明在同一印刷行有词间空白的连字符差异，与唯一命中的单字或点号差异一起列出候选。线性商式主体字符序列唯一且有括号差异时保留原图疑点。裁片覆盖发生差异的原生行，人工确认和自动入库暂停沿用现有流程。

## 替代方案

- 放宽全部浮框，直接整段覆盖模型文字。双栏或重复文字会产生误配，原生文字层也可能含有识别错误。
- 通过提示词禁止改写。提示词可以减少误差，但不能核验已有回执的字面内容。

## 后果

同一个段落中的多个错误共用一条校对记录。启用正文校对模型时，疑点先经[逐处原图复核](2026-11-19-model-pdf-source-visual-review.md)，仍未解决的项由人工依据原 PDF 确认。相邻文本相似、双栏几何不明确、扫描图缺少文字层或复杂分式读序不可靠时，匹配覆盖有限。
