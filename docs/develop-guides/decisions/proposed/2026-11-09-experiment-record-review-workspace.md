# 实验记录逐条审核工作台

状态：proposed
类型：feature
Owner：backend/package/yuxi/services/knowledge_structure_service.py

## 问题

样品和测试字段平铺后难以判断一个数值属于哪次实验。失败关联会留下零散原文取值，页面也无法保存人工调整。

## 提案

### 实现方案

文件详情实验页采用逐条审核工作台，样品目录及详情展示样品和独立制备、测量记录。审核队列提供待核对、已处理筛选及右侧出处。具备 manage 权限的人可新增记录、修改样品和字段、选择同正文版本的出处、保存待核对、确认或排除。

现有实验 revision JSON 内独立保存人工审核记录及版本。已有机器卡片按稳定位置生成记录标识，机器抽取内容可独立回读。写入由现有文档操作锁、文件行锁、正文指纹及审核版本保护，过期请求返回冲突。确认要求人工声明已核对，并要求所选出处中能定位样品和该条核心取值。

新抽取会保留被拒绝提案中已定位的关联字段，作为一条带原因的待核对记录。旧草稿仍可编辑成型记录，未归属取值可用于手工整理。孤立取值与待核对记录分别展示。

## 替代方案

直接覆盖原机器卡片无法核对人工修改前的结果。为试用工作台引入新持久化表需要存储迁移。现阶段使用已绑定正文版本的现有 revision，分别读取机器原稿和审核投影。

## 后果

确认作用于当前正文版本的一条记录。用户可以保留缺证草稿。正式问答接入属于独立发布流程。自动去重、分组值拆解只在原文足以证明的后续抽取规则中扩展。
