# 实验草稿按原文编号提取并保留可校验结果

## 问题与决定

[初版实验结构化](2026-11-06-chemical-paper-structuring.md)要求模型重复抄写事实及整段引文。一条数值与引文对不上时，其他已提取事实也无法发布。

[抽取模块](../../../../backend/package/yuxi/knowledge/structure.py)按原文段落、完整表格及围栏分批，给每个原文块和识别到的常见数值单位组合分配编号。模型优先返回编号，其他事实返回块中的逐字文本。程序回填原文和位置。关联仍按全文事实执行，归属证据必须覆盖已验证的字段位置。

舍弃无法核对的候选或关系，保留其余可核对结果。模型格式错误允许重试一次，仍失败则把对应阶段标为不完整。输入容量超限、无可校验结果的抽取失败、模型请求失败与任务失权仍显式失败。部分草稿使用现有 revision 的覆盖信息标记，继续受任务版本与 lease 校验约束。

每次模型请求记录任务 ID、阶段、模型、尝试次数、输入字符数和估算输入 token。请求结束记录耗时与供应商实际输入、输出及总 token，缺失时保留未知。日志不保存论文或模型响应。请求继续使用 `timeout=None`，任务整体执行由 Durable Task 管理。

## 替代与后果

继续要求模型抄写引文接入简单，但保留长输出和逐字复制造成的故障。按检索命中选取少量段落能缩小输入，也会改变覆盖范围。本次保留有界全文扫描，先减少模型输出，并用部署日志观察耗时和 token。

## 验证

- 使用同一篇曾失败的论文，走正常 Paper 入库，回读当前草稿、未归属事实、字段出处和 Worker 请求日志。比较同模型的请求耗时和 token，核对原文位置及表格单位。
- 在验证环境以受控模型响应返回未知编号、缺少必填字段的条目、另一原文块的数值编号、错误类型的事实引用及错误样品的归属，核对相应条目被拒绝，同批其余有效记录仍可查看且页面显示部分草稿。整批格式连续错误两次后核对批次记录。超限输入、所有事实均无法校验、模型请求错误或任务失权应明确失败。
- 核对返回实际 usage 的请求和缺少 usage 的请求分别记录真实数值和未知，并确认成功响应的格式重试也有单独的 token 日志。

部署环境人工验证待执行。
