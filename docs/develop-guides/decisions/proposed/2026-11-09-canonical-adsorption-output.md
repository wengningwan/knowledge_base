# Paper 入库生成吸附分离规范 JSON

状态：proposed
类型：feature
Owner：backend/package/yuxi/knowledge/adsorption_schema.json

身份与数量契约、当前结果下载及重新提取的后续设计见[结构化正确性与导出提案](2026-11-11-experiment-structure-correctness-and-export.md)。该提案尚待实施，本记录中的现有机器原稿行为仍以源码为准。

## 问题

Paper 入库生成的机器草稿按样品组织制备与测量卡片，缺少《结构化输出(1).docx》样例中的论文、材料、样品状态、实验、观测、曲线与出处关系。用户需要下载与附件同构的 JSON。

## 提案

### 实现方案

JSON Schema 保留 Word 示例的根字段、关联结构和已有记录变体。论文值、记录条数和编号由本次论文决定。按[实验登记与跨论文字段提案](2026-11-10-experiment-registry-and-paper-neutral-fields.md)，批次因素和通用制备条件使用有类型的原文参数，并扩展动力学实验及数值变体。样品批次、化学式和页码作为字典键时，由对应登记数据约束。未报告的数据使用契约允许的省略、空值或空列表，并通过缺失记录声明。抽取使用 Paper 冻结正文、同次解析资料和原 PDF 的页码信息。

Worker 分阶段生成论文与样品登记、实验与曲线、观测和质量记录。程序从原文块回填证据，校验输出结构与跨记录引用后，通过现有文档锁与 Task lease 保存当前版本。机器卡片从规范 JSON 投影，人工审核继续独立保存。文件详情直接下载机器 JSON 根对象。既有草稿继续可读，PDF 重新入库时生成新版结果。Paper 使用其他文件类型时照常入库。

格式、证据或引用校验可以按条拒绝。独立观测结果和制备步骤保留通过校验的成员，依赖已拒绝编号的记录也逐轮移除。题录和 PDF 物理页码仍是发布前置条件，最终 JSON 仍执行完整契约校验。印刷页码按[缺失页码提案](2026-11-10-experiment-optional-printed-pages.md)保留已知映射，未知使用 `null` 并记录说明。包含可用观测、制备步骤或可恢复人工候选的部分结果随 revision 保存，剔除原因进入原有 `validation_issues` 字段，人工候选按[校对队列提案](2026-11-10-experiment-correction-queue.md)单独保存。页面显示部分完成并保留下载入口。

题录和实验登记分别完成引用校验后提供后续阶段需要的编号。论文登记首轮引用错误复用既有一次重试；制备操作引用已登记样品产物时不重新声明身份。三个独立观测组复用文档模型并发配置和跨 Worker 准入，完成后按组序合并，再执行质量汇总。Worker 日志记录已写入 Task 的进度，以及长模型请求仍在等待的实际时长。

## 替代方案

把旧卡片重新包装为规范 JSON 可以复用已有数据，但无法恢复旧流程未提取的实验类型、样品状态和原文关系。让模型一次生成整份 JSON 可减少调用次数，但参考样例的长度会增加截断和跨记录引用错误的概率。

## 风险

样例是已填数据，未规定样例外实验类型与所有缺失值约束。模板范围外的实验结构没有可验证的字段约定。实际覆盖率与本地模型的上下文容量、输出质量及 PDF 解析结果相关。仅出现在图像中的数据依赖可引用的解析文本。基准论文图 7 中只出现于图像的带符号结合能和相互作用距离属于需人工补证的范围。
