# 按规范 JSON 阅读实验结果

状态：proposed
类型：feature
Owner：web/src/components/knowledge/ExperimentCardsPanel.vue

## 问题

实验卡片把制备、测试条件和结果混在长表中，反复展示相同出处。用户需要按已确认的原型阅读样品、实验、材料和完整 JSON，在样品内查看测试条件及制备步骤，并直接阅读公式。

## 提案

### 实现方案

文件详情继续从既有实验卡片接口读取任务与审核状态，同 revision 的 JSON 接口提供完整规范数据。规范数据可用时装配五页签工作台，旧格式草稿继续使用原审核工作台。加载、读取失败、重试及跨文件请求废弃由文件详情面板负责。

样品的测量列表使用服务端审核记录，人工保存后的结果由服务端返回值更新。实验登记、曲线、材料、缺失资料和校验说明从规范 JSON 读取，所有字段均能在原始 JSON 中访问。制备路线按当前样品的批次展示温度，样品内的条件展开和步骤切换保持当前上下文。仅一种测量类别时隐藏筛选。

审核编辑复用既有工作台表单、权限和保存回调，以弹窗承载。原始机器卡片拥有人工记录标识，制备步骤只有在原始样品卡中存在唯一同名操作，且当前记录的样品、类型和操作仍一致时关联既有审核记录。无法唯一对应时通过补录创建独立记录。非样品上下文的补录与未归属片段保持空样品，供用户按证据填写。审核版本、正文指纹和服务器冲突拒绝继续由现有用例执行。规范 JSON 始终展示机器原稿，人工记录独立保存。

公式复用项目的数学分段、KaTeX 和 Markdown 展示，正文与表格使用受控渲染，JSON 代码保留原值。界面使用现有颜色变量适配浅深色。

## 替代方案

直接复制静态 HTML 的模拟保存无法支持持久化和并发冲突。把审核修改回写机器 JSON 会改变下载契约。仅给原长表增加跳转链接仍然需要用户在多个页签间寻找同一条结果。

## 验收标准

| 验收主张 | 失败面 | 语义 Owner | 直接证据 / 命令 | 负向案例 | 当前结果 |
|---|---|---|---|---|---|
| 当前文档五页签完整读取同版 JSON | 切文档后旧响应污染新文档 | 文件详情实验面板 | 打开两篇文档，切换时检查题录与样品、下载文件 | 延迟第一篇 JSON 请求后切到第二篇，第一篇响应不得覆盖页面 | Not run，本机约定禁止运行 |
| 样品内查看条件和制备步骤 | 跳转后丢失样品或使用其他样品温度 | 规范实验工作台 | C-700-3 就地展开条件、查看 700 °C，切 C-600-3 核对 600 °C | 单类别样品不显示重复筛选，空路线显示空态 | Not run，本机约定禁止运行 |
| 人工修改持久化且保留原稿 | 乐观更新伪装成功、冲突被覆盖 | 原审核工作台与结构化用例 | 修改结果后重开文件、回读记录并下载机器 JSON | 双页面旧版本提交被服务器拒绝，失败后保留输入；只读账号无编辑入口 | Not run，本机约定禁止运行 |
| 所有 JSON 内容可访问 | 概览省略字段被误认为数据丢失 | 规范 JSON 页签 | 遍历顶层字段、嵌套对象、空值及数字化曲线点并对照下载 | 空数组、null、false 和 0 按原类型展示 | Not run，本机约定禁止运行 |
| 公式按正常上下标和分式展示 | 原文、原表或结果显示 LaTeX 标记 | 实验公式展示与既有数学渲染 | 核对 λ = 632.8 nm、25 °C、C₂H₆/C₂H₄ 及选择性分式 | 含 HTML 的原文不能执行脚本或事件，JSON 代码显示原值 | Not run，本机约定禁止运行 |
| 编辑保持明确的数据归属 | 空样品被预填、修改后仍绑定原步骤 | 规范工作台与复用编辑表单 | 从非样品页补录保持空样品，将制备记录改归其他样品后重开 | 重名操作不自动关联，原样品不可编辑已移出的审核记录 | Not run，本机约定禁止运行 |
| 页面在浅深色与窄屏可阅读 | 固定色穿帮、弹窗或原表溢出 | 工作台样式与公式显示 | 在浅深色及 1024、768、375 像素宽度检查目录、结果、出处和首次编辑弹窗 | 长段原文、完整 JSON、空列表及合并单元格表格保持可访问 | Not run，本机约定禁止运行 |

部署电脑的静态 gate 使用 `docker compose exec web pnpm run lint:check`、`docker compose exec web pnpm run build` 和 `python3 scripts/verify_engineering_contracts.py`，完成后仍按表格进行实际页面操作和结果回读。

## 风险

运行验收由用户在部署电脑完成。本机只进行源码和 diff 审阅，lint、build、工程校验和浏览器操作均为 Not run。人工记录与机器 JSON 的分离沿用现有保存契约，页面通过明确的人工记录状态区分。
