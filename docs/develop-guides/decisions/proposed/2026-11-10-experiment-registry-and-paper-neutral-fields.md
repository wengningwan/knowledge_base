# 实验登记区分产物引用并按论文表达制备与动力学数据

状态：proposed
类型：bug-fix
Owner：backend/package/yuxi/knowledge/adsorption_contract.py

## 问题

一次实验导出只剩未关联实验的定性观测，三条样品状态因编号重复被删除，制备、实验与观测再因缺少样品编号被连带删除。导出没有保留被删候选，无法还原该次全部编号冲突。源码另有可确定的缺陷：制备操作将已登记样品作为 `output_intermediate_id` 输出时，校验器把同一物料的产物引用再次登记为身份声明，连同样品状态一起判为重复。

JSON Schema 从示例固定了 KOH/沥青比例和部分只能为空的条件，无法完整表达 PAN/ZnCl₂/EDA 体系的电纺、交联及最终碳化。动力学实验、动力学选择性和扩散时间常数也没有对应记录变体。示例字段在不适用论文中被填入零，且原文已有的核心数据缺少合法承载位置。

目标是让有效登记先闭合再供后续阶段引用，并容纳原文实际制备因素、条件与动力学数据。非目标是修改完成判定、引入通用任意 JSON、自动补推未报告数据、恢复图像曲线点、修改存储 schema 或覆写人工审核。既有校对队列改动保持独立。

## 提案

### 实现方案

编号身份与引用仍由[规范契约](../../../../backend/package/yuxi/knowledge/adsorption_contract.py)拥有。制备产物与已登记样品状态编号相同时，复用该状态身份，不重复声明；新中间体仍必须唯一。真正重复的身份及悬空、类别错误引用继续拒绝。第一轮论文登记的引用校验失败时复用既有一次模型重试，错误说明带上冲突编号；再次失败后沿既有逐条过滤和人工候选流程处理。样品登记和实验登记分别在提供后续 catalog 前校验，避免下游继续引用已知无效编号。

[JSON Schema](../../../../backend/package/yuxi/knowledge/adsorption_schema.json)把批次因素改为有类型的原文参数映射，兼容已有数字和数量值，不规定 KOH 等论文特有因素。通用制备操作保留明确输入、输出、试剂、顺序、条件和出处；参数保留原文写法、值及单位，未报告项省略。登记最终样品时允许操作直接引用 `output_sample_state_ids`，不要求增加原文不存在的末端干燥步骤。

动力学实验及选择性、扩散时间常数使用明确记录变体，分别保存来源类型、样品、气体或物种对、实验条件、数值及证据编号。观测必须关联包含当前样品的动力学实验，实验已声明测量气体时观测气体也必须属于该集合。观测编排将两种结果纳入现有观测组；[数值核对及卡片投影](../../../../backend/package/yuxi/knowledge/adsorption_review.py)处理科学计数法的原文表示，倒数时间单位接受上标、负指数及斜杠写法，规范单位按完整表达核对，带单位的结果写法也须一致。扩散结果在正文中核对目标数字邻接的单位，在表格中核对目标单元格及对应表头，避免借用其他结果的单位。页面按实际因素显示样品摘要并翻译新类型，无新操作入口或配置。

顶层格式和内部存储版本保持不变，扩展接纳旧记录；推进抽取提示版本，使重新入库生成新的 revision。修改只作用于新生成结果，既有已删候选无法从下载文件自动恢复。当前完成判定、Task lease、同正文版本发布与人工记录 Owner 保持不变。

## 替代方案

关闭编号唯一性或引用校验会保留歧义和错误归属；按记录顺序改写重复编号无法确定下游引用应归属哪条记录。仅增强提示无法修复契约不允许的实验类型或条件。复制每篇论文的专用 Schema 会持续增加论文绑定；允许任意对象会失去明确的字段和类型边界。保留类型化参数、明确实验变体与身份校验能覆盖当前已观察到的输入。

现有证据为用户导出、日志和源码的只读检查（Inspected）。`git diff --check` 已执行并退出 0（Passed），只证明其覆盖的 diff 空白规则。本机不启动项目，不执行测试、构建、lint 或工程验证脚本；部署验收与原始模型候选尚未回读，不能把本记录写成实际生成通过。

单位关联的负向案例：同一引文保留两条扩散结果，只把目标结果单位从 s^-1 改为 s^-10，另一结果仍为 s^-1；候选目标值与原始单位填写 s^-1 时须拒绝。表格则把目标指标列单位改错，其他列保留 s^-1，候选也须拒绝。以上均为部署电脑的人工验收预期，当前为 Not run。

科学计数法的正向案例同时保留 Markdown 数学定界：`raw_text` 为 `$7.64\times10^{-4}$`，对应数值为 0.000764，原文邻接单位为 s^-1、规范单位为 1/s 时须保留。把带单位的 `raw_text` 写成 s 仍须拒绝。当前为 Not run。

数字边界的正向案例包含句末 `kinetic selectivity of 26.0.`，句点作为标点不影响 26.0 的核对；负向案例 `26.0.4` 不得截成 26.0 通过。当前为 Not run。

## 风险

模型仍可能生成真正歧义的编号或未报告数据；有类型字段和明确提示不能替代原文核对。新增变体需要外部 draft JSON 消费者接受，旧数据继续可读但不自动改写。当前完成判定仍可能发布只有少量文字观测的结果，此项按用户范围留待独立处理。
