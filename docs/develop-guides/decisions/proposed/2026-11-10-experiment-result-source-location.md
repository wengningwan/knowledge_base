# 实验结果按表格交点定位出处

状态：proposed
类型：bug-fix
Owner：web/src/utils/experimentPresentation.js

## 问题

样品结果的出处集合同时包含样品归属、测试方法和观测引文。把它们全部作为当前结果的出处显示，会让用户误认为每个片段都支持当前数值。未定位时仍展示第一张关联表格，会进一步暗示错误归属。表头 `(O/C)%`、`(N/C)%` 的分组括号会导致比例指标漏标，数值末尾零差异和同样品其他指标同值也需要区分。

## 提案

### 实现方案

表格展示工具在规则表格中按样品、指标表头和结果确定唯一交点。后端投影的中文指标及括号单位对应同一规范指标，再与原表的已知完整表头匹配。匹配忽略空白、数学排版标记和纯十进制数值的末尾零；百分数指标允许单元格带百分号及 LaTeX 转义百分号。保留原始引文和表格顺序，不修改机器 JSON、审核记录或后端证据关联。

规范工作台的测量记录只显示可定位当前结果的引文：规则表格要求样品、指标和取值的唯一交点；正文按既有逐字高亮的完整词和数值边界定位结果。比例表头的整体分组括号与单位括号分别处理，保留 O/C 和 N/C 的指标含义。多个可定位片段保留切换，优先展示表格；按钮与结果行页码使用同一过滤结果。无匹配时显示未定位空态，结果行不显示无关片段的页码。样品、方法等完整关联仍保留在记录和编辑表单中，不修改服务端保存契约。

Markdown 预览完成后通知调用方，工作台从实际 DOM 判断是否存在高亮；测量引文没有实际高亮时隐藏引文正文并显示未定位提示。宽屏滚动详情面板，窄屏沿实际滚动容器显示高亮。再次选择相同预览时也重新显示已有高亮。旧审核页与校对队列继续复用同一表格高亮规则。

## 替代方案

只优先包含数值的表格无法区分其他样品或其他指标的同值。仅添加未定位提示并继续展示任意关联表格仍会暗示错误归属。调整后端证据编号会涉及已保存版本和人工记录，展示修复无需改变这些持久数据。合并单元格的多层表头需要额外的表格语义解析，本决定不将其作为已定位的结果出处。

## 风险

规则表格与已知指标名之外的引文可能无法自动定位，合并表头需在编辑表单或原件人工阅读。正文逐字命中只帮助定位，不证明样品或科学语义归属。高亮不构成抽取正确或人工确认的证明。用户提供的 JSON 与 PDF 仅用于本地核对，不写入仓库。真实页面、lint、build、工程校验和文档构建均留待部署电脑执行；独立静态审查不能代替运行结果。
